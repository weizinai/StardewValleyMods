# 介绍

该模组让你能够自动的砸开晶球 (包括金色椰子，谜之盒，金色谜之盒等)。你只需要手持晶球，然后按下快捷键 (默认是F，可以在`config.json`或`GMCM`中修改)
，该模组就会开始工作。

快捷键只在晶球菜单里生效，且需要手持晶球：没手持晶球时按下不会有任何反应。晶球面板左缘外侧、与晶球区顶边齐平处也有一个开始按钮，点击该按钮与按快捷键等价。

砸一颗晶球需要 25 金。钱不够、背包满或晶球用完时，模组会像原版那样给出提示（钱箱抖动 / 「背包已满」）并自动停手，按钮文字翻回「开始」。窗口失去焦点时自动砸随游戏一起暂停，切回来会接着砸，开关状态不会丢。

# 功能

- 自动砸开晶球
- 砸开晶球快速动画：默认每帧最多跑 20 倍速，可在`GMCM`中把「晶球动画速度」调成 1~20（1 为原版速度）。装了`Fast Animations`时，砸晶球的动画速度完全交给它，本模组不再补帧，该选项也不会显示
