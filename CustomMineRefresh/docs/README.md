# 介绍

该模组按你配置的刷新策略，清理矿井与火山地牢中**没有玩家**的楼层，让旧楼层（已被挖空的矿、已开过的箱）换成新楼层。

**只需房主安装**：单人模式与房主都生效，其他玩家什么都不用做——不用装本模组，甚至不用装 SMAPI。所有判定都在房主这边做，因此不会出现各端「刷新结果」互相打架的情况。

名字里的 `Custom` 指的是**可自定义的刷新策略**：矿井与火山各有一套「开关 + 节拍」，互不影响；`Mine` 是矿洞的统称，同时涵盖矿井与火山地牢。

# 功能

- 矿井：1–120 层中无人的楼层会被清理，之后重新生成。默认**即时**（每秒检查一次），也可以改成按游戏分钟定时
- 火山地牢：1–9 层中无人的楼层按节拍清理，默认每 60 游戏分钟一次。第 0 层（入口、矮人商店与桥所在层）永不清理
- 有人所在的楼层永不清理；当天断线的玩家所留的楼层、以及正在加载中的楼层也不会被清理
- 骷髅洞穴（121 层以上）与火山顶保持原版行为，本模组不插手
- 配置（`GMCM`）共四项，分成矿井、火山两组，每组都是「开关 + 节拍」：节拍单位为游戏分钟（10 游戏分钟 ≈ 7 秒），填 `0` 表示「即时」，上限 10 游戏小时

# 注意

- 矿井是**离层即刷**：离开某一层后，那一层立刻变成新楼层，下楼再上楼就能拿到一个新楼层。这比原版更强——原版在多人下离开矿井时不会清理任何楼层，只有 10 游戏分钟一次的自检会清掉一部分（而且只清比「当前有人所在的最深层」更深的无人楼层，你已经离开的浅层会留着）；单人下虽然会在离开矿井时清理，也得先离开整个矿井才行
- 火山地牢的刷新是本模组**新增**的行为（原版一天之内从不刷新火山楼层，走的是读档或跨天时的整体清理），因此默认节拍取温和的 60 游戏分钟；如果你觉得太激进，可以把火山那组整个关掉
