## 新增

- 模组变化现在按三类报告，不再只说「谁被移除了」：悬停概览给出「已移除 / 新增 / 已更新」各有多少条，明细窗口把三类分节列出、且只显示真正有内容的分节；「已更新」项直接显示旧版本与新版本
- 也正因为新增与版本变化同样算变化，只加过模组、或只有模组升过版本的存档也会出现这个图标
- 明细窗口顶部现在多一行：记录时间、记录当时的游戏版本、以及模组数变化（记录时 -> 当前）

## 变更

- 日志系统迁移至 PiCore（移除 Common 共享项目），控制台日志仍显示各模组名
- 存档列表的图标、悬停概览与模组变化窗口改由 PiCore UI 叠层绘制，本模组不再给原版存档菜单打任何 Harmony
  补丁，因此不再与改造该菜单的模组冲突。图标仍画在存档名右侧的同一位置、命中区也没变，点存档槽照常载入该存档；概览不再是原版 tooltip，因此不再占用（也不再覆盖）原版留给删除按钮提示的那个字段
- 存档槽旁的图标现在可以点开一个列出模组变化的窗口；窗口打开期间点击不会再落到它背后的存档槽上，读明细不会误开始载入存档
- 记录文件升级为自描述形状：记录时间、游戏版本、每个模组的名称与版本。旧版本写下的记录按「没有记录过模组信息」处理、无法对比，需要把该存档载入并保存一次以写入新格式
