# 更新日志

# [待定] 1.4.2

- 配置菜单迁移至 PiCore `ConfigService`/描述器配置模块（静态 `ModConfig.Instance`）；「重置为默认」现在即时生效，无需重启
- 晶球菜单的开始按钮改用与其它菜单一致的扁平观感（尺寸略大，带悬停高亮与悬停/点击音效），并显示当前状态（「开始」/「停止」）：一眼看出自动砸是否已开启；自动停止（钱不够、背包满或晶球用完）后，文字同样翻回「开始」
- 钱不够（砸一颗要 25 金）时现在会像原版那样抖一下钱箱并显示余额不足的提示，然后停止自动砸；此前它会卡在「停止」状态又砸不动，钱箱一直抖
- 背包满时会像原版那样提示「背包已满」并停止自动砸；此前背包只剩一格就一律停手，连原版允许的「手持最后一颗」也被静默取消，玩家看不到任何原因
- 窗口失去焦点时自动砸随游戏一起暂停（与游戏的「失焦暂停」一致），切回游戏后自动接着砸、开关状态不丢；此前它会照砸不停，而失焦时按键收不到，等于刹不住车
- 快捷键只在晶球菜单内生效；未手持晶球时按快捷键不做任何事（避免按了却毫无反应）
- 「晶球动画速度」配置项现在是 1~20 的滑条（此前是无边界文本框，可以填入 0、负数或极大的值并写进 `config.json`）；它只在没安装 Fast Animations
  时生效——装了该模组时补帧完全交给它，这个选项也就不再显示，改为用它自己的速度设置；值为 1 即原版速度
- 按钮贴在晶球面板左缘外侧、与晶球区顶边齐平，改变窗口尺寸后仍在该位置；手持物品图画在按钮之上
- 按钮现在一次点击只翻转一次开关（按住不再每帧重复翻转），且这一击归按钮独占：不再顺带砸开一颗晶球
- 开始按钮现在恒定显示在晶球菜单里：「绘制开始按钮」配置项已移除，不再需要先开启
- 🔴 破坏性变更：配置项改名后，升级会把「自动砸晶球快捷键」重置为默认的 F；若你改过快捷键，更新后需要重新设置一次
