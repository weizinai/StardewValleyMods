# 介绍

该模组为小屋添加了更多的功能。

# 功能

- `拜访小屋信息`。当你拜访一个小屋时，游戏右下角会显示一条与小屋主人相关的信息。
- `小屋主人名字标签` / `总在线时间标签` / `上次在线时间标签`。在小屋上分别显示小屋主人的名字、总在线时间与上次在线时间，
  其中「上次在线时间」只在该主人离线时出现。
    - 名字按「我 / 在线 / 离线」三色区分：自己为红，在线为黑，离线默认灰
    - 观感扁平：标签面板不画投影，文字也没有阴影
    - 锚定在小屋上：标签盒中心对准小屋左上角的格子，再叠加你配置的像素偏移；标签画在世界内容之上，小屋滚出视野时整块被裁掉
    - 三个标签各自有开关与像素偏移，可在 `config.json` 或 `GMCM` 里设置
- `小屋面板`
    - 客机玩家按下快捷键会打开由 `PiCore.UI` 重做的外观面板，观感扁平（无投影）：标题下方是小屋的 4× 大预览，两侧是原版的左右箭头（悬停有提示），
      预览下方显示「3 / 7」这样的外观计数，再往下是「移动小屋」与「关闭」两个文本按钮。面板宽 760、高度随小屋美术自适应，也可以用手柄的焦点环操作。
      切换外观立即生效并同步到主机；点「移动小屋」后视口冻结在小屋上，鼠标左键拾起、再左键放下（放置格红 / 绿提示），按 Esc 或手柄 B
      结束并把你送回原来的位置（视角与界面一并复原）
    - 主机玩家使用原版木工菜单，可以移动小屋、拆除小屋和建造小屋
- `重置小屋`。你可以不删除小屋，只删除小屋主人与小屋的联系。
