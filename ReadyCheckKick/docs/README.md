# 介绍

在原版的多人游戏中，当联机的人较多时，在过夜阶段或者准备阶段常常有玩家不准备。该模组会把未准备玩家的名单列成一块面板摆在房主眼前， 并提供了自动踢出未准备玩家功能，面板上的按钮也能手动踢人。

# 功能

- `未准备玩家面板`。由 `PiCore.UI` 绘制，观感扁平（九宫格面板，不画投影）， **只有房主能看到**：
    - `准备检查时`。面板水平居中浮在原版「Waiting for other players...」对话框正上方，底边与对话框顶边留 8 像素。 每行是原版头像 +
      玩家名，行内右侧一枚「踢出」按钮，面板底部一枚「全部踢出」按钮。所有准备检查场景（睡觉、节日开始 / 结束、事件门槛、电影院等）都会出现
    - `过夜存盘等待时`。同一块面板的只读形态（只有头像与名字，没有任何按钮）锚在屏幕右上角。客机看不到这一面
    - 未准备的人数超过 5 行时可用鼠标滚轮滚动列表，滚出视口的行既不绘制也点不到；面板重新出现时列表从顶部开始
    - 没有未准备玩家时整块面板不出现，屏幕上不会多出一个空盒子
- `踢出未准备玩家`。手动踢人只有面板上的「踢出」与「全部踢出」两个按钮，都不做二次确认；被踢掉的玩家会立刻从列表里消失
    - `自动踢出`。「自动踢出未准备玩家比例」是 **已准备玩家**的占比门槛：占比超过它之后，再等「自动踢出未准备玩家延迟」秒踢出未准备的玩家。 打开「节日特殊处理」时改为另一种节奏：在节日结束前
      50 分钟踢出
    - 手动踢人只在房主端、且当前是准备检查对话框时可用——面板（含按钮）也只在此时出现
- `配置`。以下选项均可在`config.json`或`GMCM`中修改：
    - 「显示未准备玩家」分区：「在准备时显示信息」「在过夜时显示信息」两个总开关。关掉即对应的面板整块不出现 （准备检查那一面连按钮一起消失，手动踢人随之不可用，但自动踢出照常工作）
    - 「踢出未准备玩家」分区：「自动踢出未准备玩家」「自动踢出未准备玩家比例」「自动踢出未准备玩家延迟」「节日特殊处理」

面板只支持鼠标操作（悬停 + 左键 + 滚轮），没有手柄与键盘导航。
