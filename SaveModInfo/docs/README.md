# 介绍

该模组能记录上次载入存档时安装的模组，让你在「加载存档」页面就能看出这份存档的模组列表与那次记录相比变了什么。

# 功能

- `感叹号图标`。存档名右侧的感叹号表示这份存档与记录不一致——有已移除、新增或版本变化过的模组；从未记录过模组信息的存档同样显示它。与记录完全一致的存档不显示图标。
- `悬停概览`。鼠标停在图标上会出现一块跟随光标的概览面板，给出「已移除 / 新增 / 已更新」各有多少条，并提示点击图标查看明细；面板超宽自动折行，也不会跑出屏幕。
- `明细窗口`。点击图标打开窗口：按「已移除 / 新增 / 已更新」分节列出明细，「已更新」的模组显示 `旧版本 -> 新版本`，顶部一行给出记录时间、记录当时的游戏版本与模组数变化。列表可用鼠标滚轮滚动，背景压暗，
  `Esc` 或「关闭」按钮退出；窗口打开期间的点击都不会落到背后的存档槽上。

记录时机不变：载入存档时若为每月 1 号则立即记录，否则在本会话首次保存时记录。用旧版本模组写下的记录没有模组版本信息，会被当作「没有记录过模组信息」，需要把该存档载入并保存一次以写入新格式。
