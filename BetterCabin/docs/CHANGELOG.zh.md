## 变更

- 日志系统迁移至 PiCore（移除 Common 共享项目），控制台日志仍显示各模组名
- Harmony 补丁迁移至 PiCore `Patcher` API（单行 `Patch<T>` 绑定），游戏行为不变
- 配置菜单迁移至 PiCore `ConfigService`/描述器配置模块（静态 `ModConfig.Instance`，损坏配置自愈，声明式菜单含经 `AddSection` 渲染的嵌套偏移子配置分区）；
  「重置为默认」现在即时生效，无需重启
- 小屋三个世界标签（主人名字 / 总在线时间 / 上次在线时间）改由 PiCore 的世界锚定路径绘制：观感改为扁平（面板与文字都不再画投影），
  画在世界内容之上（不再被之后绘制的建筑压住），小屋滚出视野时整块被裁剪。三个标签各自的开关与偏移配置、全部配置键名与偏移单位均不变，
  且不再每帧为每个小屋分配标签对象
- 小屋主人离线时的名字默认色由白改为灰：在标签的米色面板上清晰可读，同时仍与在线玩家的黑色区分。该默认值只在没有已保存值处生效——若 `config.json` 里已存有
  `OfflineFarmerColor`，删掉该条目才会换成新的灰色
- 配置菜单各分区不再把分区标题重复成开关标签：标题保留功能名，打开该功能的开关统一显示共享的「启用」标签，界面不再出现同一句话两遍；悬停提示保留原描述文案
- 客机的小屋外观面板重做为 PiCore.UI 菜单：观感改为扁平（面板与文字都不再画投影），小屋按 4× 大预览，两侧是原版的左右箭头（新增了旧面板没有的悬停提示），
  预览下方显示「3 / 7」这样的外观计数；原来的移动 / 关闭图标按钮换成「移动小屋」（悬停提示沿用原版「移动建筑」文案）与「关闭」两个文本按钮。面板宽 760、
  高随预览自适应，以屏幕高度封顶，仍放不下时窗口居中、内容裁切。切换外观仍即时生效并同步到主机，移动小屋的操作不变。面板音效改用 PiCore 菜单统一的那套：
  悬停与点击按钮都播共享的悬停 / 确认音，不再播旧面板自己播的两个音效（切换外观时一个、进入移动模式时一个），「关闭」按钮只播这一声确认音

## 修复

- 「重置小屋」的选择提示改为询问要重置哪些玩家，与其打开的玩家列表一致（此前询问的是「小屋」）
- 英文文案两处清理：「重置小屋」的成功提示不再在玩家名前多一个 "The"；加入白名单的提示不再混入中文全角逗号，同句的 "you cabin" 更正为 "your cabin"
